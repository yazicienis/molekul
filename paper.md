# Summary

MOLEKUL is a teaching platform for ab initio quantum chemistry. It is designed for students who have met the equations of Hartree--Fock theory, Moller--Plesset perturbation theory, coupled-cluster theory, density-functional theory, and molecular response methods, but who have not yet seen how those equations become executable code. The project pairs a small pure-Python library with a 14-notebook curriculum. Each notebook introduces the theory, calls the actual implementation in `src/molekul`, and compares selected results against PySCF where an external reference is appropriate.

MOLEKUL is not a production alternative to PySCF or Psi4. It deliberately favors readable NumPy implementations over screening, density fitting, integral libraries, or large-system performance. The core electronic-structure routines use NumPy arrays and standard Python. SciPy is a runtime dependency for geometry optimization through `scipy.optimize`; notebook and validation extras add PySCF, Matplotlib, Jupyter, and py3Dmol. The intended classroom use is to inspect, step through, and modify small calculations: H2, H2O, N2, first-row basis-set examples, and one-dimensional model periodic systems.

# Statement of need

Computational chemistry courses often face a gap between textbook derivations and research software. Production packages such as PySCF and Psi4 are open and scriptable, but they are engineered for broad functionality and practical calculations [@sun2020; @smith2020]. They are excellent targets for validation and for later research work; they are not always the shortest path from an equation in lecture notes to the loops, tensor contractions, and convergence checks that implement it.

Several educational and prototyping projects already address parts of this gap. eChem provides notebook-based quantum-chemistry teaching material built around VeloxChem workflows [@fransson2023echem]. Psi4NumPy combines Psi4 and NumPy for education, reference implementations, and rapid prototyping [@smith2018psi4numpy]. DQC focuses on differentiable quantum chemistry with PyTorch/autograd [@kasim2022dqc]. SlowQuant emphasizes readable Python implementations [@slowquant], PyQuante2 continues the Python quantum-chemistry line [@pyquante2], PyFock focuses on Gaussian-basis DFT with JIT/GPU acceleration [@pyfock], and Qiming Sun's book gives a full-stack Python route into quantum-chemistry programming [@sun2025pythonqc]. The free and open-source education context is reviewed by Lehtola and Karttunen [@lehtola2022foss]. MOLEKUL differs in the combination it offers: a NumPy-centered code path with no compiled extension in the core MOLEKUL implementation, one uniform API across constants, integrals, SCF, correlation, DFT, excited states, gradients, visualization, population analysis, and periodic/phonon model problems, and a sequential 14-notebook curriculum that uses the same implementation throughout.

# Curriculum

The notebooks are meant to be used in order. Notebook 00 checks the environment and gives the roadmap. Notebooks 01--04 build atoms, molecules, Gaussian basis functions, one-electron and two-electron integrals, and restricted Hartree--Fock. Notebooks 05--07 add geometry optimization, visualization, population analysis, MP2, and harmonic frequencies. Notebooks 08--10 cover CCSD, CCSD(T), DFT, UHF, CIS, TD-DFT/TDA, and EOM-CCSD on small systems. Notebooks 11--12 introduce semi-numerical gradients, the optional CuPy backend, one-dimensional Bloch sums, bands, density of states, and phonons. Notebook 13 is a capstone workflow that runs the main molecular pieces on one example.

# Validation

The current validation tables are generated by `python benchmarks/validation_table.py` and committed as `benchmarks/validation_table.md`, `benchmarks/validation_table.json`, `benchmarks/periodic_validation.md`, and `benchmarks/periodic_validation.json`. The molecular table contains 30 method/basis cells against PySCF 2.12.1. The M1 gate labels 23 cells as `ok` and 7 as `experimental`; no cells are hidden. Experimental cells include PBE, wider-basis LDA/TD-DFT cases, and broken cc-pVDZ DFT grid behavior that must not be cited as validated. The periodic mini-validation records two H-chain checks: qualitative Gamma-to-X band monotonicity and the analytic acoustic phonon sum rule at Gamma. These tables are the source of numeric claims in this paper.

# Availability and reuse

MOLEKUL is distributed under the MIT license. The repository includes tests, scripts that regenerate benchmark tables, and notebooks that can be executed headlessly with the `notebooks` extra installed. The source archive for v0.2.0 is available at \url{https://doi.org/10.5281/zenodo.20558145}.
